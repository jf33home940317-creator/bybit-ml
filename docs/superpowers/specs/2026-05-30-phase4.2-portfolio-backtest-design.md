## 目標

在 Phase 4.1 確認 ETHUSDT × target_atr 訊號有效性之後，Phase 4.2 為真實資金導入三條「設計規則檢查（DRC）」，將純訊號評估升級為具備機構級風控的投資組合模擬：

1. **動態風險部位控管（Fixed Risk Sizing）** — 每筆交易最多虧損帳戶淨值 2%
2. **併發部位上限（Concurrency Control）** — MAX_CONCURRENT = 3，允許同幣種分批建倉
3. **資金複利與真實路徑相依（True Path Dependency）** — 帳戶餘額動態流動，複利累積

**目標**：將 Phase 4.1 ETHUSDT × target_atr 的 -45% 最大回撤（未風控），壓制到 15% 以下，同時維持正期望值的指數型資金曲線。

**初始虛擬資金：** 1,000,000 USD / 組合（各組合獨立帳戶）

## 模組設計

### backtest/simulator.py

#### `run_portfolio_simulation(df, feature_cols, fold_models, target, optimal_threshold, initial_equity=1_000_000, risk_pct=0.02, max_concurrent=3) -> dict`

**Phase 1：預先計算所有訊號的交易結果（忽略併發）**

```python
proba = generate_oof_probabilities(df, feature_cols, fold_models)
signal_indices = np.where(proba >= optimal_threshold)[0].tolist()
raw_trades_df = compute_trade_pnl(df, signal_indices, target)

raw_trades_df['exit_bar'] = (raw_trades_df['entry_idx']
                              + raw_trades_df['holding_bars']).astype(int)
raw_trades_df['atr_at_entry'] = df['atr_14'].values[
    raw_trades_df['entry_idx'].values.astype(int)]
raw_trades_df = raw_trades_df.sort_values('entry_idx').reset_index(drop=True)
```

**Phase 2：事件驅動順序迴圈**

```
狀態：
    equity    = initial_equity
    open_slots: list[dict]    ← 至多 max_concurrent 筆
    closed_trades: list[dict]
    equity_log: list[(exit_bar, equity)]   ← 步階資金曲線資料點
    skipped   = 0

for each row in raw_trades_df（時間順序保證）:

    ── A. 釋放容量（exit_bar ≤ entry_idx 的舊倉先平倉）──
    to_close = [t for t in open_slots if t['exit_bar'] <= row.entry_idx]
    依 exit_bar 升序排列 to_close
    for t in to_close:
        equity += t['pnl_usd']
        equity_log.append((t['exit_bar'], equity))
        closed_trades.append({...t, 'trade_roe': t['pnl_usd'] / t['equity_at_entry']})
    open_slots = [t for t in open_slots if t['exit_bar'] > row.entry_idx]

    ── B. 併發上限檢查 ──
    if len(open_slots) >= max_concurrent:
        skipped += 1
        continue

    ── C. 動態部位計算 ──
    if target == 'target_fixed':
        sl_distance = row.entry_price * 0.01        # 1% 固定 SL
    else:  # target_atr
        sl_distance = 1.5 * row.atr_at_entry        # 動態 ATR SL
    risk_budget  = equity * risk_pct                # 本筆最大虧損 USD
    position_qty = risk_budget / sl_distance        # 買進數量
    position_usd = position_qty * row.entry_price   # 名目倉位大小
    pnl_usd      = position_usd * row.pnl           # row.pnl 已含 0.2% 手續費

    ── D. 登記開倉 ──
    open_slots.append({
        'entry_idx':      row.entry_idx,
        'exit_bar':       row.exit_bar,
        'timestamp':      row.timestamp,
        'outcome':        row.outcome,
        'entry_price':    row.entry_price,
        'exit_price':     row.exit_price,
        'atr_at_entry':   row.atr_at_entry,
        'sl_distance':    sl_distance,
        'position_qty':   position_qty,
        'position_usd':   position_usd,
        'pnl_pct':        row.pnl,
        'pnl_usd':        pnl_usd,
        'equity_at_entry': equity,   ← 開倉當下帳戶淨值，用於 Portfolio Sharpe
    })

迴圈結束後 flush 剩餘開倉（按 exit_bar 升序）:
    for t in sorted(open_slots, key=exit_bar):
        equity += t['pnl_usd']
        equity_log.append((t['exit_bar'], equity))
        closed_trades.append({...t, 'trade_roe': t['pnl_usd'] / t['equity_at_entry']})
```

**2% Rule 數學守恆驗證：**

```
SL 觸發時：
    pnl_usd = position_qty × entry_price × (−sl_pct − fee)
            = position_qty × (−sl_distance) − position_qty × entry_price × fee
            = −risk_budget − fee_usd
            ≈ −equity × 0.02 − 0.002 × position_usd

即：最大虧損 ≈ 帳戶淨值的 2.2%（含手續費），數學上自洽。
```

**回傳 dict 鍵值：**

| 鍵 | 型別 | 說明 |
|----|------|------|
| `closed_trades` | `list[dict]` | 所有已平倉交易紀錄（含 trade_roe） |
| `equity_log` | `list[(bar, equity)]` | 步階資金曲線資料點 |
| `final_equity` | `float` | 最終帳戶淨值 |
| `total_signals` | `int` | OOF 訊號總數 |
| `executed_trades` | `int` | 實際成交筆數 |
| `skipped_signals` | `int` | 因容量上限跳過的訊號數 |
| `metrics` | `dict` | 下方所列指標 |

---

### 指標計算

| 指標 | 公式 |
|------|------|
| `final_equity` | 最後一筆 equity_log 的 equity 值 |
| `total_return_pct` | `(final_equity / initial_equity − 1) × 100` |
| `cagr_pct` | `((final_equity / initial_equity)^(1/total_years) − 1) × 100` |
| `sharpe_ratio` | `mean(trade_roe) / std(trade_roe, ddof=1) × √(n_trades / total_years)` |
| `max_drawdown_usd` | `min(equity_arr − np.maximum.accumulate(equity_arr))` |
| `max_drawdown_pct` | `max_drawdown_usd / peak_equity_at_trough × 100` |
| `win_rate` | `sum(pnl_usd > 0) / executed_trades` |
| `avg_position_usd` | `mean(position_usd)` |
| `avg_holding_bars` | `mean(exit_bar − entry_idx)` |

**Sharpe 說明：** 使用 `trade_roe = pnl_usd / equity_at_entry`（帳戶級回報），反映複利環境下真實的風險調整後績效，非原始資產報酬率。

`total_years = len(df) / 8760`（與 Phase 4.1 一致）

### run_portfolio_backtest.py

```python
COMBINATIONS = [
    ("ETHUSDT", "target_atr", 0.75),   # 主力
    ("BTCUSDT", "target_atr", 0.79),   # 對照組
]

for symbol, target, threshold in COMBINATIONS:
    df, feature_cols, fold_models = load_assets(symbol, target)
    results = simulator.run_portfolio_simulation(
        df, feature_cols, fold_models, target,
        optimal_threshold=threshold,
    )
    reporter.save_portfolio_report(results, symbol, target, backtest_dir)
    reporter.save_portfolio_equity_curve(results, symbol, target, backtest_dir)
```

`optimal_threshold` 從 `{symbol}_{target}_threshold_scan.json` 的 `optimal_threshold` 欄位讀取（不寫死）。

## 測試策略

| 測試 | 驗證內容 |
|------|---------|
| `test_concurrent_limit` | MAX=3 時第 4 個訊號被跳過（skipped=1），open_slots 不超過 3 |
| `test_capacity_release` | exit_bar ≤ entry_idx 的舊倉先釋放容量，後到的訊號得以進場 |
| `test_position_sizing_2pct` | SL 觸發時 `abs(pnl_usd) ≈ equity_at_entry × 0.02 + fee_usd`（容差 1e-6） |
| `test_equity_compounds` | 勝倉平倉後，下一筆 `position_usd` 比上一筆大（Anti-Martingale 自動生效） |
| `test_no_open_trades_leak` | 模擬結束後 `open_slots` 為空，`len(closed_trades) == executed_trades` |
